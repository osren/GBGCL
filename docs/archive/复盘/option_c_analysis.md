## 二、各数据集详细分析

### CS 数据集


| 指标       | 初始   | 执行后 | 变化   |
| ---------- | ------ | ------ | ------ |
| mean       | 0.9428 | 0.9384 | -0.44% |
| std        | 0.0000 | 0.0012 | -      |
| num_trials | 1      | 20     | +19    |

**分析**：CS 数据集在增大 ball_loss_weight 后反而下降了 0.44%。初始结果只有 1 trial，最终结果用了 20 trials。mean 下降说明更大的球级损失对 CS 产生了负面影响。

**原因推测**：CS 数据集本身粒球结构已经很好（ detach + center 模式），过强的球级损失可能干扰了已有的好的粒球结构。

---

### Photo 数据集


| 指标       | 初始   | 执行后 | 变化   |
| ---------- | ------ | ------ | ------ |
| mean       | 0.9381 | 0.9372 | -0.09% |
| std        | 0.0015 | 0.0007 | 收窄   |
| num_trials | 6      | 20     | +14    |

**分析**：Photo 下降 0.09%，但 std 从 0.0015 降至 0.0007，稳定性提升了约一半。

**原因推测**：Photo 的粒球结构对 ball_loss_weight 不敏感，增大权重无法带来提升，但有助于稳定性。

---

### Computers 数据集


| 指标       | 初始   | 执行后 | 变化   |
| ---------- | ------ | ------ | ------ |
| mean       | 0.8997 | 0.8984 | -0.13% |
| std        | 0.0007 | 0.0007 | 持平   |
| num_trials | 5      | 20     | +15    |

**分析**：Computers 下降 0.13%，与 Photo 类似。

**原因推测**：Computers 使用 homo + dot + 0.7（高 alpha），说明更依赖原始特征而非粒球增强。

---

### Physics 数据集


| 指标       | 初始   | 执行后 | 变化   |
| ---------- | ------ | ------ | ------ |
| mean       | 0.9621 | 0.9624 | +0.03% |
| std        | 0.0002 | 0.0004 | 略增   |
| num_trials | 5      | 20     | +15    |

**分析**：Physics 是唯一提升的数据集！+0.03% 虽然很小，但是正向的。

**原因推测**：Physics 数据集粒球结构不够稳定，需要更强的球级损失来规范化粒球内部结构。

---

## 三、原因总结

### 为什么大部分数据集下降？

1. **粒球模块在当前架构中影响力太小**

   - 只在 epoch 0 构建一次（gb_rebuild_every=50~100）
   - 回写结果不参与下一轮训练
   - ball_loss_weight 从 0.05 增大到 0.3 只是让一个"不重要的模块"变得更重要了一点，但没有从根本上改变架构
2. **BYOL 损失依然主导**

   ```python
   loss = loss_node + 0.3 * loss_ball_scatter + 0.1 * loss_ball_infonce
   # BYOL 依然占 60%+，粒球模块不是瓶颈
   ```
3. **不同数据集特性不同**

   - CS：粒球结构已经很好，不需要更强的约束
   - Physics：粒球结构不稳定，需要约束 → 唯一提升

## 四、改进方向总结


| 优先级 | 改进方向                              | 预期效果           | 难度 |
| ------ | ------------------------------------- | ------------------ | ---- |
| 高     | 增加粒球更新频率 (每 5-10 epoch 重建) | 保持粒球与嵌入同步 | 中   |
| 高     | 信息传递（将扩散结果写入节点特征）    | 累积效应           | 高   |
| 中     | Target 分支增强                       | 双分支都受益       | 低   |
| 低     | 继续调 ball_loss_weight               | 已验证效果有限     | -    |

---

## 五、结论

Option C（增大 ball_loss_weight）的实验验证结果是：

- **Physics 略微提升 (+0.03%)** - 数据集特性所致
- **其他三个数据集下降或持平** - 说明这不是通用改进
- **根本问题不在损失权重，而在于架构设计**

**核心问题**：粒球模块没有真正融入主训练流程，需要从架构层面重新设计迭代式传播机制。
