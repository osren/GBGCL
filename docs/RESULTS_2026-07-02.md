## 二、Phase 0 SGRL 基线

Phase 0 结果存储在独立目录 `results/phase0_sgrl/`（注意：与后续阶段的 `results/` 目录分开）。

### 查看命令

```bash
# 各数据集基线统计
for ds in CS Photo Physics Computers; do
  echo -n "$ds: "
  awk -F, 'NR>1{sum+=$5; sq+=$5*$5; n++} END{mean=sum/n; std=sqrt(sq/n-mean*mean); printf "%.5f ± %.5f (n=%d)\n", mean, std, n}' results/phase0_sgrl/${ds}_summary.csv
done
```

### Phase 0 基线结果

| 数据集 | SGRL 论文 | Phase 0 基线 | 差距 |
|--------|-----------|-------------|------|
| CS | 94.15% | 93.67% ± 0.08% | -0.48% |
| Photo | 93.95% | 93.91% ± 0.07% | -0.04% |
| Physics | 96.23% | 96.22% ± 0.03% | -0.01% |
| Computers | 90.23% | 90.04% ± 0.03% | -0.19% |

> Phase 0 基线低于论文，可能因为论文取 5 trials 最佳而非平均，或有额外调参。

## 四、结论与问题

### 亮点
- **CS 超越论文**：粒球扩散对 CS 提升显著（+0.61% vs 基线，+0.13% vs 论文）
- Physics/Computers 基本持平

### 问题
1. **Photo 反而下降**（-0.20%）：Stage-B 选的最优参数在 Photo 上过拟合或运气差
2. **粒球效果有限**：Photo/Physics/Computers 上 ball_loss_weight=0.05 太小，扩散几乎无作用
3. **Phase 2 阻塞**：BTCM/BRSM 未实现，无法测试将粒球融合进 TCM 路径

### 下一步建议
1. BTCM/BRSM 实现后重跑 Phase 2
2. Photo/Computers 用 Phase 0 基线参数单独验证，排除 Stage-B 过拟合
3. 考虑增大 `ball_loss_weight`（当前 0.05）测试敏感性
