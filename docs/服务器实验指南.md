## 扫参环境变量

| 环境变量 | 含义 | 推荐值 |
|---------|------|--------|
| `SWEEP_STAGE` | `A`=粗筛 150ep×1，`B`=精训 700ep×5 | 由 `phase3_*.sh` 自动设置 |
| `SWEEP_WORKERS` | 并行进程数 | Stage-A: 2；Stage-B: 1 |
| `SWEEP_DEVICE` | 设备 | `cuda` |
| `RESULTS_DIR` | CSV 输出目录 | 默认 `results/` |
| `DEVICE` | `train.py` 设备 | `cuda` |

---

## 输出文件位置

| 文件 | 位置 |
|------|------|
| 实验结果 CSV | `results/<dataset>_summary.csv` |
| 分阶段训练 log | `logs/phases/phaseN/` |
| nohup 输出 | `logs/nohup/` |
| 运行台账 | `logs/phases/journal.csv` |
| Top 配置 | `analysis/overall_topk.csv` |
| sweep 详细 log | `logs/phases/phase3a/sweep_stage_a.log` 等 |

---

## 注意事项

1. **断点续跑**：`sweepX.py` 检查已有 CSV，已完成组合自动跳过。
2. **Physics OOM**：`SWEEP_WORKERS=1` 或降低 `hidden_dim`。
3. **数据集**：`datasets/` 需在服务器单独准备，不在 Git 中。
